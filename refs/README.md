# refs — рілси, які тобі подобаються

Сюди кидаєш чужі рілси, з яких хочеш взяти подачу: хук, темп, субтитри, ефекти, звук.
Claude розбирає їх за скілом reel-reference і записує твій стиль у `STYLE.md`.

Як зберегти рілс:
- Instagram: «Поділитися» → «Завантажити», якщо автор дозволив. Немає кнопки — запис екрана (Пункт керування → запис екрана), потім обріж початок і кінець.
- TikTok: «Поділитися» → «Зберегти відео».
- YouTube Shorts: запис екрана.

Назви файл так, щоб памʼятати, що в ньому подобається: `хук-з-цифрою.mp4`, `субтитри-капсула.mp4`.
Тримай тут 3–5 штук. Більше — гірше: стиль розмивається.

Референс — для прийомів, а не для копії: чужий текст, графіку й музику не беремо.
