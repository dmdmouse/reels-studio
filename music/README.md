# music — музика під рілси

Клади сюди лише музику, на яку маєш право: власну, з бібліотек без авторських обмежень (наприклад, YouTube Audio Library, Pixabay Music) або куплену ліцензію.

Порада: трендовий звук краще додати вже в застосунку Instagram/TikTok під час публікації — так алгоритм бачить, що ти використовуєш популярний трек. У студії монтуй «без музики» або з тихою фоновою.
