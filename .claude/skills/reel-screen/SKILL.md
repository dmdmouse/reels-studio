# Запис екрана → рілс

`PY` = `.venv/bin/python` (Mac) або `.venv\Scripts\python` (Windows). Потрібен HyperFrames (скіл **studio-setup**, розділ «Моушн-графіка»). Шаблон — `motion/screen/index.html`.

## 0. Перед записом скажи людині
Одна дія від початку до кінця. Вимкнути сповіщення, сховати особисті дані й чужих клієнтів, збільшити масштаб браузера до 150 %. Запис: Mac — QuickTime або Cmd+Shift+5, Windows — Win+Alt+R. Голос можна записати одразу. Хоче бути в кадрі — паралельно знімає себе на телефон.

## 1. Текст і нарізка
```
PY tools/reels.py plan inbox/<запис> --name <назва>
```
Прибери очікування завантаження й помилки, але лиши причину й наслідок: людина має бачити, куди клацають і що вийшло. Покажи план, дочекайся «так». У `edl.json` додай `"raw": true` і зроби:
```
PY tools/reels.py render work/<назва>/edl.json --out work/<назва>/screen.mp4
```

## 2. Автор (якщо є)
Розпізнай відео з телефона (`transcribe`). Зсув — різниця часу першого спільного слова в обох `words.json`. Обріж телефонне відео так само за цими ж інтервалами, щоб рот збігався з голосом.

## 3. Сцена
Скопіюй `motion/screen/` у `work/<назва>/screen-scene/`. В `assets/`: `screen.mp4`, `author.mp4` (без звуку, `-g 30`), `voice.m4a`, `sfx/*.wav`. Заміни `data-duration` на тривалість. Співвідношення сторін запису: якщо не 880×684, постав `height` у `#screenBox`, `#zoom`, `#screen`. Без автора — прибери `#authorBox`.

Наїзди: `to(fx, fy, масштаб, секунда)`, де `fx, fy` — точка екрана від 0 до 1. Наїжджай лише на те, що дрібно, на слові, яке про це говорить, за 0,5 с до дії. Не їдь, поки людина читає. 2–4 наїзди на 30 с, масштаб не більше 2. Подивись кадри: важливе не обрізане.

```
npx -y hyperframes check
npx -y hyperframes snapshot --at 1,4,8
npx -y hyperframes render -o ../../../output/<назва>/<назва>-v1.mp4 --quality delivery
```

## 4. Субтитри
Скіл **reel-captions**, внизу: вони лягають під екран. Перевірка: `check --listen`.

## Правила
- Інтерфейс, зібраний у HTML (Living UI), — це макет. Якщо глядачу важлива правда, показуй справжній запис.
- Текст у записі має читатись на телефоні. Не читається — наїзд або більший масштаб браузера.
