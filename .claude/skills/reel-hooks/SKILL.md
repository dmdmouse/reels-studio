# Три варіанти хука

Хук — перші 2–3 секунди. Він має одразу сказати глядачу, що він отримає або чому має зупинитись. Вигадані обіцянки й цифри — заборонено: беремо лише те, що людина сказала або підтвердила.

## 1. Знайди кандидатів
Прочитай `work/<назва>/plan.md`. Обери 3 фрази, які можуть стояти першими:
- **результат** («Цей рілс я не монтував жодної секунди»);
- **проблема глядача** («Монтаж забирає в тебе 3 години?»);
- **несподіванка/факт** («46 ефектів зробив один промпт»).

## 2. Покажи людині
Таблиця: варіант, перша фраза, заголовок на екрані (до 6 слів), чому спрацює. Спитай, які 2–3 рендерити.

## 3. Зроби версії
Для кожного варіанта:
1. Копія `edl.json` → `edl-hook-a.json` (b, c). Обрана фраза — першою, решта в тому ж порядку; якщо фраза дублюється далі — прибери повтор.
2. `PY tools/reels.py render work/<назва>/edl-hook-a.json --out output/<назва>/<назва>-hook-a.mp4`
3. Субтитри з `--title "<заголовок>"` (скіл reel-captions).
4. `check` кожної версії.

## 4. Віддай
Три файли поруч + одне речення про кожен. Порада: опублікуй одну, а дві інші — через кілька днів як нові рілси або тестуй у Trial Reels Instagram.
