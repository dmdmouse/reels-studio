# Розбір референсу → STYLE.md

Референс — це орієнтир для стилю, а не копія. Чужий текст, графіку й музику не переносимо, лише прийоми.

## 1. Файл
- **Є посилання** (YouTube, Shorts, TikTok, Instagram): `PY tools/reels.py fetch <посилання> --name <назва>` → `refs/<назва>.mp4`.
- Instagram інколи не віддає відео без входу. Тоді попроси людину натиснути «Зберегти» / записати екран і покласти файл у `refs/`. Паролі від соцмереж не проси.
- Референс скачуємо лише для розбору прийомів, не для повторної публікації.

## 2. Що витягти (`PY` — див. reel-edit)
1. Текст із таймкодами: `PY tools/reels.py transcribe refs/<назва>.mp4 --lang <мова>`
2. Кадри: `PY tools/reels.py check refs/<назва>.mp4` → аркуш 9 кадрів.
3. Темп (скільки склейок): 
   `ffmpeg -i refs/<назва>.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep -c pts_time`
   → склейок на хвилину = кількість / тривалість × 60.

## 3. Запиши `STYLE.md` (у корені студії)
- **Хук**: перші 3 секунди — що кажуть і що на екрані.
- **Структура**: хук → … → заклик (з таймкодами).
- **Темп**: склейок за хвилину; середня довжина фрази.
- **Субтитри**: розмір, колір, де стоять, скільки слів, чи є підсвітка → найближчий наш стиль (pop/plain/box, `--color`).
- **Графіка/ефекти**: що з'являється і навіщо → найближчі ефекти з бази 46 (номери).
- **Звук**: музика (темп, гучність), звукові ефекти.
- **Що повторюємо в себе**: 3–5 конкретних прийомів.

## 4. Підсумок
Коротко людині: 3 прийоми, які варто взяти, і як знімати під цей стиль (кількість планів, де стояти). Далі рілси монтуємо за STYLE.md — додай рядок «Монтуй за STYLE.md» у CLAUDE.md, якщо людина погодиться.
