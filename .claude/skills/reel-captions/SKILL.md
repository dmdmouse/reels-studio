# Субтитри

`PY` = `.venv/bin/python` (Mac) або `.venv\Scripts\python` (Windows).

## Команда
```
PY tools/reels.py captions <відео> --style pop|plain|box --place bottom|top|center [--title "ХУК|другий рядок"] [--fixes work/fixes.json] [--prompt "Claude, Reels"]
```
- **pop** — великі літери, активне слово жовте, «вистрибує». Для динамічних рілсів.
- **plain** — білий текст із контуром, без ефектів. Для спокійних і експертних.
- **box** — текст на темній плашці. Коли фон строкатий.
- `--color` — колір активного слова у форматі BBGGRR (жовтий 00E5FF, помаранчевий 1C4AFF, зелений 4EFCA9).
- `--title` — великий заголовок угорі на перші 2,5 с; `|` — перенос рядка.

## Порядок
1. Прочитай слова з CLAUDE.md «Слова, які Whisper пише неправильно» → передай їх у `--prompt`.
2. Запусти команду. Відкрий `work/<назва>/captions.ass` і прочитай текст: шукай неправильні слова, імена, бренди.
3. Помилки → `work/fixes.json`: `{"клод": "Claude", "рілз": "Reels"}` (ключ — як написав Whisper, без розділових знаків) → запусти знову з `--fixes`.
4. `PY tools/reels.py check <результат>` → подивись аркуш кадрів:
   - субтитри на обличчі → зміни `--place` (обличчя низько — `top`; високо — `bottom`);
   - конфліктують із текстом на екрані чи ефектом → інше місце;
   - заголовок перекриває голову → коротший текст або без `--title`.
5. Нова спроба — нова назва файлу через `--out`.

## Правила
- На екрані лише те, що людина сказала. Не перефразовуй.
- Не більше 3 слів на екрані одночасно для pop.
- Не клади субтитри ближче ~100 px до країв.
