# Довге відео → кілька рілсів

`PY` = `.venv/bin/python` (Mac) або `.venv\Scripts\python` (Windows).

## 1. Текст
```
PY tools/reels.py plan inbox/<файл> --name <назва> --prompt "<слова з CLAUDE.md>"
```
Прочитай `work/<назва>/plan.md`: кожен рядок — фраза з часом.

## 2. Кандидати
Знайди 5–10 шматків по 15–60 с. Оцінюй кожен за 100 балами:

| Критерій | Вага | Питання |
|---|---|---|
| Хук | 30 | Перша фраза зупиняє? Сильне твердження, питання, обіцянка |
| Зрозуміло без контексту | 25 | Людина, що не бачила решти, зрозуміє? Немає «як я казав», «це», «той» без пояснення |
| Емоція | 20 | Є думка, подив, гумор, чесність |
| Користь | 15 | Можна взяти й застосувати або запамʼятати |
| Фінал | 10 | Закінчується думкою, а не обривається |

Покажи таблицю, найкращі зверху, і дочекайся вибору:

| # | Час | Сек | Бали | Перша фраза | Чому |
|---|---|---|---|---|---|

Межі — лише початок і кінець фраз з `plan.md`. Слова не переставляй і не вигадуй.

## 3. Кадр
Якщо відео горизонтальне: `ffmpeg -ss <час> -i inbox/<файл> -frames:v 1 work/<назва>/frame.jpg`, подивись, де людина. Значення `x`: 0 — ліворуч, 0.5 — центр, 1 — праворуч. На кадрах із кількома людьми `x` став окремо на кожну фразу.

## 4. Монтаж
Для кожного вибраного шматка створи `work/<назва>-N/edl.json`:
```json
{"name": "<назва>-N", "x": 0.5, "clips": [{"src": "inbox/<файл>", "start": 130.3, "end": 158.7}]}
```
Паузи й «е-е» всередині прибери: кілька записів у `clips`, по одному на фразу. Далі:
```
PY tools/reels.py render work/<назва>-N/edl.json
PY tools/reels.py check output/<назва>-N/<назва>-N-v1.mp4 --listen
```
Прочитай, що чути: думка закінчена, дублів немає. Субтитри — скіл **reel-captions**.

## Правила
- Хук не вигадуємо: якщо сильна фраза в середині шматка, запропонуй почати з неї.
- Один рілс — одна думка. Дві думки — два рілси.
