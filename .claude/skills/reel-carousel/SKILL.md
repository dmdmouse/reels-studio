# Карусель із думки

## 1. Зміст
Джерело — текст людини: рілс (`work/<назва>/plan.md`), нотатка або повідомлення. Факти й цифри — лише її.
Структура 5–8 слайдів:
1. **Обкладинка** — одна сильна думка до ~8 слів (без «у цьому пості…»).
2–(n−1). **По одній ідеї на слайд**: заголовок до 6 слів + 1–2 речення.
n. **Заклик** — що зробити (з CLAUDE.md «Заклик»).
Покажи тексти людині й дочекайся «так».

## 2. Файл слайдів
`work/<назва>-carousel.json`:
```json
{"palette": "light", "handle": "@нік",
 "slides": [{"title": "Обкладинка"}, {"title": "Ідея 1", "text": "Пояснення."}, {"title": "Заклик", "text": "Напиши …"}]}
```
Палітри: `light` (білий, останній слайд темний), `dark`, `horizon`, `paper`, `poster`, `classic`, `soft`, `pop`, `agency`, `creator`.

## 3. Рендер і перевірка
```
PY tools/reels.py carousel work/<назва>-carousel.json
```
→ `output/carousel-<назва>-carousel/01.png …`. Відкрий 2–3 слайди: текст не налазить на низ, нічого не обрізано. Є «⚠️ забагато тексту» — скороти саме той слайд.
