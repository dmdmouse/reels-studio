# Reels студія

Тека-студія для монтажу рілсів у Claude Code. Ти кидаєш відео з телефона, Claude ріже паузи й дублі, ставить субтитри, ефекти, анімації й звук. Монтаж іде на твоєму комп'ютері, відео нікуди не відправляються.

## Старт одним промптом

Потрібні застосунок Claude і план, де є вкладка Code (Pro або вище).

1. Створи порожню теку «Reels студія» в Документах і відкрий її у вкладці Code.
2. Встав промпт і заміни слова в дужках:

```
Постав мені Reels студію в цю теку: https://github.com/dmdmouse/reels-studio
Клонуй репозиторій прямо сюди. Якщо git немає, скачай zip гілки main і розпакуй так, щоб CLAUDE.md лежав у корені цієї теки.
Прочитай CLAUDE.md і виконай .claude/skills/studio-setup/SKILL.md. Я на [Mac / Windows].
Потім познайомся зі мною за .claude/skills/about-me/SKILL.md. Мій блог: [про що, якою мовою].
Каталог інших відео-скілів: https://github.com/zhuyansen/awesome-claude-video-skills. Нічого звідти не став. Запиши його в CLAUDE.md як місце, де шукати нове, коли мені чогось бракуватиме.
```

Перший запуск займає 10–20 хвилин: модель розпізнавання мови важить близько 1,5 ГБ і завантажується один раз.

Коли Claude напише «ВСЕ ГОТОВО ✅», поклади відео в `inbox/` і напиши: «Змонтуй inbox/[файл] за скілом reel-edit».

## Що всередині

- `.claude/skills/`: 11 скілів: налаштування, знайомство, монтаж, рілси з довгого відео, запис екрана, субтитри, ефекти, стилі моушн-графіки, хуки, референси, карусель.
- `tools/reels.py`: інструмент монтажу.
- `motion/`: 10 стилів анімації для HyperFrames і готові вставки.
- `sfx/`: звуки CC0.
- `PROMPTS.md`: усі промпти.

Це лише текст, шаблони й звуки. Встановлюються безкоштовні відкриті програми: ffmpeg, Python, Whisper, yt-dlp, а для анімацій HyperFrames і Remotion. Скіл `reel-effects` працює з Базою 46 ефектів, вона йде окремо в курсі.

## Курс

[Reels студія](https://maxdiachuk.com/reels-studio/): 4 дні покроково, База 46 ефектів, кейси й група.
